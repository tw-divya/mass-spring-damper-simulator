Mathematical Modelling and Simulation of a Mass-Spring-Damper System

Differential equations with constant coefficients, Laplace transforms and RK4 numerical integration, in one interactive laboratory. Engineering Mathematics PBL, Modules 5 and 6.

Start laboratoryExplore mathematical theory

Key equations

m x″ + c x′ + k x = F(t)
X(s) = [F(s) + m s x(0) + m x′(0) + c x(0)] / (m s² + c s + k)
G(s) = 1 / (m s² + c s + k)
ωn = √(k/m), ζ = c / (2√(mk))

Objectives

  • Model the system with a second-order constant-coefficient ODE.
  • Solve it with the Laplace transform and its inverse.
  • Check an RK4 numerical solution against the exact one.
  • Compare underdamped, critically damped and overdamped responses.
